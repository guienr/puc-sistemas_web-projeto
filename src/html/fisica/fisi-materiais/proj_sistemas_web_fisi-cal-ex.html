Exercícios sobre Calorimetria

Resolva os exercícios abaixo para testar seus conhecimentos sobre os conceitos de calor e trocas térmicas:

1. O que é calor específico?

  • A) A quantidade de calor necessária para fundir uma substância
  • B) A quantidade de calor necessária para elevar a temperatura de 1g de uma substância em 1°C
  • C) A quantidade de calor liberada por uma reação química
  • D) A capacidade de uma substância de conduzir calor

Resposta correta: B

2. Qual é a unidade de medida do calor no Sistema Internacional?

  • A) Watt
  • B) Joule
  • C) Caloria
  • D) Kelvin

Resposta correta: B

3. Em uma troca de calor entre dois corpos, o calor cedido é:

  • A) Maior que o calor recebido
  • B) Menor que o calor recebido
  • C) Igual ao calor recebido
  • D) Nulo

Resposta correta: C

4. Qual equação é usada para calcular o calor sensível?

  • A) Q = m · L
  • B) Q = m · c · ΔT
  • C) Q = c · ΔT
  • D) Q = m · ΔT

Resposta correta: B

5. Durante a fusão de um sólido, a temperatura:

  • A) Aumenta continuamente
  • B) Diminui
  • C) Permanece constante
  • D) Oscila

Resposta correta: C

6. O calor latente é utilizado em:

  • A) Mudanças de temperatura
  • B) Mudanças de estado físico
  • C) Reações químicas
  • D) Condução térmica

Resposta correta: B

7. Um corpo de 100g recebe 400 cal e sua temperatura varia 10°C. Qual é seu calor específico?

  • A) 0,4 cal/g°C
  • B) 4 cal/g°C
  • C) 40 cal/g°C
  • D) 0,04 cal/g°C

Resposta correta: A

8. Em um sistema isolado, dois corpos trocam calor. O corpo A cede 300 cal. O corpo B recebe:

  • A) 150 cal
  • B) 300 cal
  • C) 600 cal
  • D) 0 cal

Resposta correta: B

9. Qual fator não influencia diretamente na quantidade de calor sensível?

  • A) Massa
  • B) Calor específico
  • C) Variação de temperatura
  • D) Pressão atmosférica

Resposta correta: D

10. O que acontece com a energia térmica em um sistema isolado?

  • A) É perdida para o ambiente
  • B) É absorvida pela atmosfera
  • C) É conservada dentro do sistema
  • D) É transformada em luz

Resposta correta: C
