Adjetivos - Exercícios

Resolva os exercícios abaixo para testar seus conhecimentos sobre o uso e classificação dos adjetivos:

1. Qual das palavras abaixo é um adjetivo?

  • A) Casa
  • B) Alegre
  • C) Correr
  • D) Rapidamente

Resposta correta: B

2. Em “menina estudiosa”, o adjetivo é:

  • A) Menina
  • B) Estudiosa
  • C) Em
  • D) Nenhuma das anteriores

Resposta correta: B

3. Qual alternativa apresenta um adjetivo composto?

  • A) Feliz
  • B) Amável
  • C) Luso-brasileiro
  • D) Claro

Resposta correta: C

4. O adjetivo “inteligente” está no grau:

  • A) Comparativo
  • B) Superlativo
  • C) Normal
  • D) Absoluto sintético

Resposta correta: C

5. Qual frase apresenta um adjetivo no grau superlativo absoluto sintético?

  • A) Ela é mais rápida que ele.
  • B) Ele é muito simpático.
  • C) A menina é inteligentíssima.
  • D) João é tão forte quanto Pedro.

Resposta correta: C

6. Em “os alunos dedicados”, o adjetivo está flexionado em:

  • A) Gênero masculino e número singular
  • B) Gênero feminino e número plural
  • C) Gênero masculino e número plural
  • D) Gênero neutro e número plural

Resposta correta: C

7. Qual alternativa apresenta uma locução adjetiva?

  • A) Amor paterno
  • B) Casa bonita
  • C) Olhar de mãe
  • D) Criança feliz

Resposta correta: C

8. O adjetivo “verde-claro” é:

  • A) Simples
  • B) Primitivo
  • C) Derivado
  • D) Composto

Resposta correta: D

9. Em “o céu azul”, o adjetivo “azul” concorda com:

  • A) O verbo
  • B) O sujeito
  • C) O substantivo “céu”
  • D) Nenhuma das anteriores

Resposta correta: C

10. Qual alternativa apresenta um adjetivo derivado?

  • A) Feliz
  • B) Triste
  • C) Amoroso
  • D) Forte

Resposta correta: C
