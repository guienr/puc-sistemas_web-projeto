Logaritmo


O logaritmo é uma operação matemática inversa da exponenciação. Em outras palavras, o logaritmo de um número é o expoente ao qual a base deve ser elevada para se obter esse número.





1. Definição


Seja a um número real positivo diferente de 1, e x um número positivo. O logaritmo de x na base a é o número y tal que:

ay = x   ⇔   loga(x) = y





2. Exemplo


Considere log2(8). Como 2³ = 8, então:

log2(8) = 3





3. Propriedades dos Logaritmos


  • loga(1) = 0   → qualquer número elevado a 0 é 1.
  • loga(a) = 1   → a base elevada a 1 é ela mesma.
  • loga(x · y) = loga(x) + loga(y)
  • loga(x / y) = loga(x) - loga(y)
  • loga(xn) = n · loga(x)
  • loga(x) = logb(x) / logb(a)   (mudança de base)




4. Aplicações


Logaritmos são usados em diversas áreas como:

  • Ciências naturais (física, química, biologia)
  • Economia e finanças (crescimento exponencial, juros compostos)
  • Informática (complexidade algorítmica)
  • Engenharia (decibéis, escalas logarítmicas)
