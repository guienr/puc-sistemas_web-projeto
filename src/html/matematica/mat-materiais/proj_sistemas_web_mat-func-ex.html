Exercícios sobre Funções

Resolva os exercícios abaixo para testar seus conhecimentos sobre Funções matemáticas:

1. Qual é a definição de uma função?

  • A) Uma relação entre números inteiros
  • B) Uma fórmula que sempre resulta em zero
  • C) Uma relação entre dois conjuntos onde cada elemento do domínio está associado a um único elemento do contradomínio
  • D) Um gráfico com pontos aleatórios

Resposta correta: C

2. Qual é a forma geral de uma função afim?

  • A) f(x) = ax² + bx + c
  • B) f(x) = ax
  • C) f(x) = ax + b
  • D) f(x) = log(x)

Resposta correta: C

3. O gráfico de uma função afim é:

  • A) Uma parábola
  • B) Uma reta
  • C) Uma curva exponencial
  • D) Uma hipérbole

Resposta correta: B

4. Qual é o domínio da função f(x) = 1/x?

  • A) Todos os números reais
  • B) Todos os números reais exceto zero
  • C) Apenas os números inteiros
  • D) Apenas os números positivos

Resposta correta: B

5. Qual é a imagem da função f(x) = x² para x ∈ ℝ?

  • A) ℝ
  • B) ℝ⁺
  • C) ℝ⁺ ∪ {0}
  • D) ℝ⁻

Resposta correta: C

6. A função f(x) = |x| é chamada de:

  • A) Função quadrática
  • B) Função modular
  • C) Função afim
  • D) Função logarítmica

Resposta correta: B

7. Qual é o valor de f(2) para a função f(x) = 3x - 1?

  • A) 5
  • B) 6
  • C) 7
  • D) 4

Resposta correta: A

8. Qual das opções representa uma função exponencial?

  • A) f(x) = x²
  • B) f(x) = 2x
  • C) f(x) = x + 3
  • D) f(x) = log(x)

Resposta correta: B

9. Qual é o valor de x para que f(x) = 0 na função f(x) = 2x - 4?

  • A) x = 2
  • B) x = -2
  • C) x = 4
  • D) x = 0

Resposta correta: A

10. Qual das alternativas representa uma função logarítmica?

  • A) f(x) = log2(x)
  • B) f(x) = 2x
  • C) f(x) = x²
  • D) f(x) = |x|

Resposta correta: A
