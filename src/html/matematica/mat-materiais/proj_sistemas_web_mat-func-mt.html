Funções


Em matemática, uma função é uma relação entre dois conjuntos, onde a cada elemento do primeiro conjunto (domínio) está associado um único elemento do segundo conjunto (contradomínio).





1. Definição Formal


Uma função f de um conjunto A para um conjunto B é uma regra que associa a cada elemento x ∈ A um único elemento f(x) ∈ B.





2. Notação


A notação mais comum é: f: A → B, onde f(x) representa o valor da função para o elemento x.





3. Tipos de Funções


  • Função Afim: f(x) = ax + b
  • Função Quadrática: f(x) = ax² + bx + c
  • Função Exponencial: f(x) = ax
  • Função Modular: f(x) = |x|
  • Função Logarítmica: f(x) = loga(x)





4. Domínio e Imagem


O domínio de uma função é o conjunto de todos os valores de entrada (x) para os quais a função está definida.
A imagem é o conjunto de todos os valores de saída (f(x)) que a função pode assumir.





5. Gráficos


O gráfico de uma função é a representação visual dos pares ordenados (x, f(x)) no plano cartesiano. Cada tipo de função possui uma forma característica de gráfico.





6. Importância das Funções


Funções são fundamentais na matemática e em diversas áreas do conhecimento, como física, economia, engenharia e ciência da computação. Elas permitem modelar fenômenos, resolver problemas e entender relações entre variáveis.
