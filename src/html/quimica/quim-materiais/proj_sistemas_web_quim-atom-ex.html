Atomística - Exercícios

Resolva os exercícios abaixo para testar seus conhecimentos sobre a estrutura e os modelos atômicos:

1. Qual partícula subatômica possui carga negativa?


  • A) Próton
  • B) Nêutron
  • C) Elétron
  • D) Núcleo


Resposta correta: C

2. Qual cientista propôs o modelo do “pudim de passas”?


  • A) Dalton
  • B) Rutherford
  • C) Bohr
  • D) Thomson


Resposta correta: D

3. O número atômico de um elemento corresponde ao número de:


  • A) Nêutrons
  • B) Elétrons
  • C) Prótons
  • D) Núcleons


Resposta correta: C

4. Qual modelo atômico introduziu a ideia de órbitas quantizadas?


  • A) Dalton
  • B) Rutherford
  • C) Bohr
  • D) Thomson


Resposta correta: C

5. O que diferencia um átomo de outro elemento químico?


  • A) O número de nêutrons
  • B) O número de elétrons
  • C) O número de prótons
  • D) A massa atômica


Resposta correta: C

6. Qual partícula subatômica não possui carga elétrica?


  • A) Elétron
  • B) Próton
  • C) Nêutron
  • D) Núcleo


Resposta correta: C

7. Qual modelo atômico foi o primeiro a considerar a existência de um núcleo?


  • A) Dalton
  • B) Rutherford
  • C) Bohr
  • D) Modelo Quântico


Resposta correta: B

8. A massa atômica é calculada pela soma de:


  • A) Prótons e elétrons
  • B) Elétrons e nêutrons
  • C) Prótons e nêutrons
  • D) Elétrons e massa do núcleo


Resposta correta: C

9. O que são orbitais no modelo quântico?


  • A) Caminhos circulares fixos dos elétrons
  • B) Regiões de alta probabilidade de encontrar elétrons
  • C) Áreas onde estão os prótons
  • D) Linhas de força do campo elétrico


Resposta correta: B

10. Qual partícula subatômica define a identidade química de um elemento?


  • A) Nêutron
  • B) Elétron
  • C) Próton
  • D) Núcleo


Resposta correta: C
