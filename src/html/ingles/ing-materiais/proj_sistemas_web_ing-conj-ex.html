Conjunctions - Exercícios

Resolva os exercícios abaixo para testar seus conhecimentos sobre o uso das conjunções em inglês:

1. Qual das palavras abaixo é uma conjunction?

  • A) Quickly
  • B) Because
  • C) Beautiful
  • D) Always

Resposta correta: B

2. Complete: "I was tired, ___ I went to bed early."

  • A) or
  • B) but
  • C) so
  • D) because

Resposta correta: C

3. Qual das opções é uma coordinating conjunction?

  • A) Although
  • B) Because
  • C) And
  • D) Since

Resposta correta: C

4. Complete: "She didn’t go to the party ___ she was sick."

  • A) but
  • B) because
  • C) or
  • D) so

Resposta correta: B

5. Qual par representa uma correlative conjunction?

  • A) And / But
  • B) Because / Since
  • C) Either / Or
  • D) Although / Yet

Resposta correta: C

6. Complete: "You can have tea ___ coffee."

  • A) and
  • B) or
  • C) but
  • D) so

Resposta correta: B

7. Qual conjunção expressa contraste?

  • A) So
  • B) Because
  • C) But
  • D) And

Resposta correta: C

8. Complete: "He is not only smart ___ also kind."

  • A) or
  • B) but
  • C) and
  • D) but also

Resposta correta: D

9. Qual conjunção subordinativa indica tempo?

  • A) If
  • B) When
  • C) Because
  • D) Although

Resposta correta: B

10. Complete: "I will go to the beach ___ it doesn’t rain."

  • A) unless
  • B) because
  • C) and
  • D) but

Resposta correta: A
